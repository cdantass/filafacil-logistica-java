# FilaFácil Logística

Aplicação local de terminal para gerenciamento de solicitações de coleta.

## Tecnologias

- Java
- Git
- Persistência local em arquivo

## Funcionalidades planejadas

- Cadastrar coletas
- Listar coletas
- Filtrar por status
- Filtrar por prioridade
- Atualizar o status de uma coleta
- Gerar resumo operacional
- Salvar e carregar dados localmente

## Executando o projeto

Compile os arquivos:

```bash
javac -d out src/com/filafacil/model/*.java src/com/filafacil/view/*.java src/com/filafacil/Main.java
